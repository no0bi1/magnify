## About

Magnify is a simple add-on which allows you to use the mousewheel to zoom in and out on the world map. The zoom eases smoothly towards each wheel step (a quarter more or less each notch) and keeps the point under the cursor in place; you can drag the map while it is still moving. The add-on comes with a set of basic customization options which can be set via the `/magnify` chat command.
